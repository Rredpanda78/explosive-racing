# Explosive Racing

甩尾集氣、N2O 衝刺，再用機槍與火箭把對手轟出賽道的網頁賽車遊戲。
電腦與手機瀏覽器都能玩，使用 three.js + TypeScript + Vite。

**線上試玩：** https://rredpanda78.github.io/explosive-racing/

## 操作

| 動作 | 鍵盤 | 手機 |
|---|---|---|
| 駕駛 | ↑ ↓ ← → | 自動油門，左下 ◀ ▶，右下角煞車 |
| 甩尾 | Shift | 右下「甩尾」 |
| N2O | Ctrl（或空白鍵） | 「N2O」，甩尾後會變成「小噴」 |
| 主武器 / 副武器 | Z / X | 右側兩顆（圖示跟著裝備的武器） |
| 後視 | C | 「後視」 |
| 重置到賽道 | R | — |
| 暫停 | Esc | 右上 II |

## 玩法

- **地圖**：雲頂山道（草原、黃昏）、赤岩峽谷（沙漠、正午、大落差）、霓虹灣岸（夜間街道賽、跨海大橋）、星港高架（夜港高架道路：連續直角彎、雙髮夾彎、四座跳台）、金林飛躍（林間四連跳台、四個髮夾彎與連續 S 彎）。
- **捷徑**：每張地圖各一條較窄的小路（入口有「捷徑」指示牌，小地圖上是黃色虛線），大約省 50～70 公尺，但路窄、撞牆風險高。
- **機關**：雲頂山道山脊上有兩座左右擺盪的大鐵鎚；赤岩峽谷的長下坡會有落石滾下來（N2O 可以直接撞碎，也能用武器打碎）；霓虹灣岸的平交道會有電車橫越，燈號閃爍時要小心。
- **模式**：競速賽（跑完 2 圈比名次）、淘汰賽（每 17 秒淘汰最後一名，撐到最後）。
- **甩尾**：點一下甩尾並按住方向可以拖漂很久，反打方向盤回正；結束瞬間再按一次 ↑（手機按 N2O）觸發小噴。甩尾中撞牆，這次甩尾集到的氣會歸零。集氣量比最初版本少 20%。
- **破風與變形**：甩尾時車身兩側拖出白色氣流，開 N2O 時兩側翼片展開、尾翼升起，車頭包著一層藍色破風氣流。
- **集氣**：甩尾最快；打中對手、擊毀（直接送一瓶 N2O）、跟在別人正後方吃尾流、飛越跳台、踩加速帶也都會集氣。最多存兩瓶。
- **起跑衝刺**：倒數到 GO 的瞬間才按下油門（手機按 N2O）。
- **主武器**（車身兩側，過熱制，一律朝正前方、沒有自動瞄準）：.50 機槍、六管機槍（要預熱）、火焰發射器（近距離扇形、會讓目標持續燃燒）、雷射槍（光束瞬間命中，要持續照住）。
- **副武器**（冷卻制）：火箭炮（直射）、榴彈發射器（拋射）、地雷（放在車尾，有車經過就爆炸，最多同時 3 顆）、集束圓雷（往後撒 5 顆，碰到就炸、6 秒後自爆）、追蹤導彈（隨機鎖定一台對手追蹤，被鎖定的人會收到警告，急轉可以甩掉）。地雷可以被子彈或爆炸提前引爆。
- **武器升級**：每升一級傷害 +15%；Lv.3 主武器過熱變慢、副武器冷卻縮短；Lv.5 解鎖專屬特性（穿甲彈、快速預熱、烈焰、貫穿光束、雙聯火箭、子母彈、重型地雷、加量圓雷、雙彈頭導彈）。
- **電腦難度**：主選單可選簡單／普通／困難。困難的電腦比你快、會走捷徑、出彎有小噴，還帶著升級過的武器。
- **擊中回饋**：打中對手會跳出傷害數字，爆炸在路面留下焦痕，子彈打到護欄會濺火花。
- **碰撞**：車有重量差異，重車會把輕車撞開；側面擦撞會打轉；開著 N2O 撞人傷害加倍、自己幾乎不受傷。爆炸會把附近的車炸飛。
- **爆炸桶**：賽道邊的紅色油桶被子彈、火箭或車撞到會爆炸，還會連鎖引爆。
- **任務**：每場隨機三個任務，完成有額外獎金。
- **車款特性與花色**：五款車除了數值不同，各有一個專屬特性（備用氣瓶、甩尾大師、流線車身、重裝底盤、後燃器），每款車有三種花色可選。
- **設定**：畫質（低／中／高）、音樂與音效音量、比賽配樂風格（電子、Lo-fi、嘻哈、金屬、8-bit）、畫面震動、傷害數字；手機還可以改用傾斜轉向，並拖曳調整每顆按鈕的位置與大小。
- **車庫**：獎金可以買車款（五種，能力各有偏重）、買武器、升級武器與車輛。存檔在瀏覽器本機。

## 開發

```bash
npm install
npm run dev      # 本機開發伺服器
npm run simtest  # 無畫面模擬測試（地形檢查、AI 跑完兩種模式、甩尾檢查）
npm run build    # 型別檢查並打包到 dist/
```

推送到 `main` 後，GitHub Actions 會自動打包並部署到 GitHub Pages。

## 程式結構

- `src/game/`：純模擬邏輯，不依賴畫面（賽道、甩尾物理、武器、碰撞、AI、比賽流程、任務、地形高度）。之後做連線對戰時由主機端直接執行。
- `src/render/`：three.js 畫面（模型載入、賽道與地形、車輛、特效、後製、鏡頭）。`themes.ts` 定義每張地圖的天空、光線與景物風格。
- `src/ui/`：HUD、選單、車庫、結算畫面。
- `src/game/config.ts`：手感與平衡參數集中在這裡。

## 素材來源

- 車體：作者用 Tripo 生成的 Q 版車（`public/models/tripo/`），武器與配件會依車體外型自動對位。
- 零件、場景與備用卡丁車：[Kenney](https://kenney.nl) 的 Car Kit 與 Racing Kit，CC0 授權，放在 `public/models/`。
- 賽道、地形、天空、觀眾、特效為程式生成；音效與配樂用 WebAudio 即時合成，沒有使用任何音檔。
